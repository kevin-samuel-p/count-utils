NAME
    morse

DESCRIPTION
    Work with Morse code numbers.
    Supports counting runs using Morse code and translation
    to and from Hindu-Arabic numerals.
=
USAGE
    count morse <option>

OPTIONS
    run (r)
        Start a counting run using Morse code numbers.
        Generates alternating values.

    solorun (s)
        Start a solo counting run using Morse code numbers.
        Generates consecutive values.

    convert (c)
        Convert a numeric input into Morse code.
        Convert Morse code input into a Hindu-Arabic number.
=
EXAMPLES
    count morse run
    count morse r

    count morse solorun
    count morse s

    count morse convert
    count morse c
=
NOTES
    - No additional parameters are required.
    - Input must be either a non-negative number or a valid Morse code number.
