NAME
    palindrome

DESCRIPTION
    Work with palindromic numbers.
    Supports counting runs where numbers are palindromes.
    A palindrome is a number that reads the same forward and backwards.
=
USAGE
    count palindrome <option>

OPTIONS
    run (r)
        Start a counting run using palindromic numbers.
        Generates alternating values.

    solorun (s)
        Start a solo counting run using palindromic numbers.
        Generates consecutive values.

    check (c)
        Checks whether a user-inputted number is a palindrome.
=
EXAMPLES
    count palindrome run
    count palindrome r

    count palindrome solorun
    count palindrome s

    count palindrome check
    count palindrome c
=
NOTES
    - No additional arguments are taken.
    - Input must be a non-negative number.
    - Single-digit numbers do not count as palindromes.
    - Leading zeroes (0s at the start of the number) are stripped and do not count.
=
