NAME
    roman

DESCRIPTION
    Work with Roman numerals.
    Supports counting using Roman numbers and conversion
    to and from Hindu-Arabic numerals.
=
USAGE
    counter roman <option> <output_format>

OPTIONS
    run (r)
        Start a counting run using Roman numerals.
        Generates alternating values.

    solorun (s)
        Start a solo counting run using Roman numerals.
        Generates consecutive values.
=
OUTPUT FORMATS
    legal (l)
        Uses correct standard notation for Roman numerals, disregarding the use of M
        when a combining overline can be applied instead.
        Default output format if parameter is not explicitly specified.
            Example: 13500 -> X̅I̅I̅I̅D

    idiomatic (i)
        Prefers using M wherever possible, making numbers more verbose.
        Non-standard, stylistic choice.
            Example: 13500 -> X̅MMMD
=
EXAMPLES
    counter roman run legal
    counter roman r

    counter roman solorun idiomatic
    counter roman s i
=
NOTES
    - Input must be a non-negative number or a valid Roman numeral.
    - If output format is not specified, the legal representation format will be used by default.
=
