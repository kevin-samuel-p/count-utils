NAME
    octal

DESCRIPTION
    Work with octal numbers.
    Supports counting runs and conversion between octal and other bases.

USAGE
    counter octal <option> [argument]

OPTIONS
    run (r)
        Start a counting run using octal numbers.
        Generates alternating values.

    solorun (s)
        Start a solo counting run using octal numbers.
        Generates consecutive values.

    convert (c)
        Convert an octal number to another base.

CONVERSION TARGETS
    binary (b, bin)
        Convert octal to binary.

    decimal (d, dec)
        Convert octal to decimal.

    hexadecimal (h, hex)
        Convert octal to hexadecimal.
        
EXAMPLES
    counter octal run
    counter octal r

    counter octal solorun
    counter octal s

    counter octal convert binary
    counter octal c b

    counter octal convert decimal
    counter octal c d

    counter octal convert hexadecimal
    counter octal c h

NOTES
    - run and solorun do not take additional arguments.
    - Input must be a valid octal number less than 2000000000000000000000 (21 digits).
