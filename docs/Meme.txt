NAME
    meme

DESCRIPTION
    Work with meme numbers such as "69" and "420".
    Supports counting runs using numbers that contain specific meme digits.
=
USAGE
    counter meme <option> <meme_number>

OPTIONS
    run (r)
        Start a counting run using the selected meme number.
        Generates alternating values based on the meme number.

    solorun (s)
        Start a solo counting run using the selected meme number.
        Generates consecutive values based on the meme number.
=
MEME NUMBERS
    69
        Numbers containing "69".
        Example: counter meme r 69

    420
        Numbers containing "420".
        Example: counter meme r 420

    69420
        Numbers containing "69" or "420".
        Example: counter meme r 69420
=
EXAMPLES
    counter meme run 69
    counter meme r 69

    counter meme solorun 420
    counter meme s 420

    counter meme run 69420
    counter meme r 69420
=
NOTES
    - Input must be a non-negative number.
    - The <meme_number> argument is required for all options.
=
