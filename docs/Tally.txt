NAME
    tally

DESCRIPTION
    Work with tally marks.
    Supports counting using tally mark representations
    and conversion to and from numeric values.
=
USAGE
    count tally <option> <format>

OPTIONS
    run (r)
        Start a counting run using tally marks.
        Generates alternating values.

    solorun (s)
        Start a solo counting run using tally marks.
        Generates consecutive values.

    convert (c)
        Convert a number to its tally mark representation
        (using strikethrough formatting where appropriate),
        or evaluate tally marks to determine their numeric value.
=
FORMATS
    default (d)
        Uses default formatting (maximum 50 tallies per line).
        Default format if parameter is not explicitly specified.

    compact (c)
        Uses compact formatting (removes newline characters).

    big (b)
        Uses large text formatting for tallies.

    giant (g)
        Uses giant text formatting for tallies.

    impact (i)
        Uses impact formatting (slightly enlarged and bold text).

    tiny (t)
        Uses tiny text formatting.
=
EXAMPLES
    count tally run
    count tally r d
    count tally run big
    count tally r b

    count tally solorun compact
    count tally s c

    count tally convert
    count tally c
=
NOTES
    - If format is not specified for run or solorun, default format (d) is used.
    - convert does not require a format parameter.
    - Input must be a non-negative number or a valid tally mark sequence.
    - Tally mark grouping follows standard 5-mark convention
      (four vertical marks with a strikethrough for the fifth).
=
