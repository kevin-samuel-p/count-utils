NAME
    emoji

DESCRIPTION
    Work with emoji-formatted numbers.
    Supports emoji counting runs and conversion of numbers into emoji form.
=
USAGE
    counter emoji <option>

OPTIONS
    run (r)
        Start a standard emoji counting run.
        Generates alternating emoji-formatted values.

    solorun (s)
        Start a solo emoji counting run.
        Generates consecutive emoji-formatted values.

    convert (c)
        Convert a numeric input into its emoji representation.

    emojify (e)
        Alias for convert.
        Convert a numeric input into its emoji representation.
=
EXAMPLES
    counter emoji run
    counter emoji r

    counter emoji solorun
    counter emoji s

    counter emoji convert
    counter emoji c

    counter emoji emojify
    counter emoji e
=
NOTES
    - No additional parameters are required.
    - Input must be a non-negative number.
=
