NAME
    ternary

DESCRIPTION
    Work with ternary numbers (base 3).
    Supports ternary counting runs and base conversion.
=
USAGE
    count ternary <option> [target]

OPTIONS
    run (r)
        Start a standard ternary counting run.
        Generates alternating ternary values.

    solorun (s)
        Start a solo ternary counting run.
        Generates consecutive ternary values.

    convert (c) <target>
        Convert a ternary number to another base.
=
CONVERSION TARGETS
    binary (b, bin)
        Convert ternary to binary.
    
    decimal (d, dec)
        Convert ternary to decimal.

    hexadecimal (h, hex)
        Convert ternary to hexadecimal.

    octal (o, oct)
        Convert ternary to octal.
=
EXAMPLES
    count ternary run
    count ternary r

    count ternary solorun
    count ternary s

    count ternary convert decimal
    count ternary c d
=
NOTES
    - run and solorun do not accept additional parameters.
    - Input must be a valid ternary number lesser than 11112220022122120101211020120210210211221.
