Syntax of the Command Line Interface Tool:

counter [mode] [option] [arguments]

A counting mode is a specific counting system used in a counting channel.
Several counting modes are currently supported by the bot. These are listed below.

• binary
• decimal / normal
• emoji
• hexadecimal
• increasing
• japanese
• octal
• meme
• mirror
• morse
• norep
• nwn
• nwnwn
• nwnwnn
• palindrome
• rep
• roman
• tally

To learn more about a specific counting mode and to see the available options or arguments for that mode, type:

counter help [mode]

Please note that the command line syntax is case-sensitive, and all commands follow lowercase.
